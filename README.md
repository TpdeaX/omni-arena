# OMNI ARENA · 2D & 3D Skill Mastery

Entrenador multigénero en **2D y 3D** (Canvas 2D + Three.js + Web Audio API) con **10 disciplinas independientes**, rotación estilo Gauntlet (`OMNI GAUNTLET`), calibración global (`TEST RANKED`), gráfico radar de 5 ejes y **dificultad dinámica adaptativa**.

## Disciplinas incluidas
- **3D (Three.js):** `3D AIM LABS`, `HYPER TUNNEL 3D`, `ORBIT BREAKER 3D`, `SKY VAULT 3D`
- **2D (Canvas + Web Audio):** `RHYTHM OVERDRIVE`, `FLASH PARRY DUEL`, `BULLET HELL & GRAZE`, `MIND MATRIX`, `BLITZ STACKER`, `TWIN-STICK ARENA`

## Ecosistema conectado
Parte de un ecosistema PWA instalable en móvil y escritorio junto con:
- **Atelier Diario** (`../atelier-diario/`)
- **UNUmbral** (`../UNUmbral/`) — basado en el proyecto MIT de [@TeVerde29](https://github.com/TeVerde29/UNUmbral)
