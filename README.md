# OMNI ARENA · 2D & 3D Skill Mastery

Entrenador multigénero en **2D y 3D** (Canvas 2D + Three.js + Web Audio API) con **26 disciplinas independientes** (18 pruebas rápidas de circuito + 8 academias guiadas), rotación estilo Gauntlet (`CIRCUITO TOTAL`), calibración global (`PRUEBA CLASIFICATORIA`), gráfico radar de 5 ejes, **Práctica Guiada sin perder vidas** y **dificultad dinámica adaptativa**.

## Disciplinas incluidas (26 modos)
- **Academias Guiadas (8):** `AJEDREZ ACADEMIA`, `DAMAS TÁCTICAS`, `PÓKER EDUCATIVO`, `CUBO RUBIK 3D`, `PIANO MAESTRO`, `MATRICES LÓGICAS`, `SUDOKU RAZONADO`, `TORRES DE HANÓI`
- **Acción 3D (5, Three.js):** `PUNTERÍA TÁCTICA 3D`, `TÚNEL HIPER 3D`, `ROMPEÓRBITA 3D`, `SALTO CELESTE 3D`, `VUELO DE PORTALES 3D`
- **Destreza 2D (13, Canvas + Web Audio):** `RITMO SOBRECARGA`, `ANILLO SÓNICO`, `DUELO DE REFLEJO`, `LLUVIA Y ROCE`, `MATRIZ MENTAL`, `TABLA SCHULTE PRO`, `N-BACK CUÁNTICO`, `BLOQUES RELÁMPAGO`, `ARENA DOBLE MANDO`, `RASTREO QUIRÚRGICO`, `MEMORIA RELÁMPAGO`, `SERPIENTE NEÓN`, `CAZADOR DE REFLEJOS`
